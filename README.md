# Snello

Snello is a native Swift/SwiftUI markdown viewer and editor for macOS, built to be low-RAM and small in binary size with no Electron/WebView overhead.

This repository hosts only the **direct-download DMG releases** of Snello — no source code. Snello's source is maintained in a private repository.

## Download

Grab the latest `.dmg` from the [Releases page](https://github.com/MinTALI/snello-releases/releases/latest).

The DMG is notarized and signed with a Developer ID certificate — macOS Gatekeeper will let it run without extra steps.
