  # Snello

  A native, low-RAM markdown viewer and editor for macOS.

  [![Latest release](https://img.shields.io/github/v/release/MinTALI/snello-releases?label=latest&color=blue)](https://github.com/MinTALI/snello-releases/releases/latest)

</div>

---

Snello is built Swift/SwiftUI native — no Electron, no WebView — so it opens instantly and stays light in memory, even with large files open.

## Download

**[Download the latest .dmg](https://github.com/MinTALI/snello-releases/releases/latest)**

The build is notarized and Developer ID–signed, so Gatekeeper lets it run with no extra steps — open the DMG, drag Snello to Applications.

This repository holds only release binaries. Snello's source is maintained privately.
